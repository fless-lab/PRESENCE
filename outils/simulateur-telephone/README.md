# Simulateur de téléphone

Sert à tester les observateurs et le serveur sans dépendre de l'application Android, et à simuler plusieurs étudiants pour la démonstration et les tests de charge.

Deux variantes possibles :
- un script Python sur PC, avec la bibliothèque Bluetooth `bleak` ;
- un ESP32 de rechange programmé pour se comporter comme un téléphone (même clé, même protocole).

Il doit être présenté comme un outil de test, jamais comme le produit.
